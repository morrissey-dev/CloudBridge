# CloudBridge V1.3 — objective tracking, question audit, and local backup

**Scope:** Additive update on top of the V1.2 project. No changes to the stored exam, lesson, or scenario schemas and no deployment changes.

## Improvements

1. **Learning objectives dashboard:** A new sidebar page lists all **63** deduplicated objectives from `Learning objective.docx`, their linked lessons, and their practical-scenario evidence.
2. **Distinct progress signals:** Shows lesson completion, latest result on linked scenarios, and voluntary learner confidence *separately*. Confidence is not measured mastery or certification readiness.
3. **Find what to revise:** Filter objectives by learning module or self-assessed confidence and search by topic.
4. **Privacy-conscious backups:** Download the platform's known progress localStorage keys as one JSON file, optionally import after seeing the file's date and number of entries and confirming replacement. No upload is performed. Store the file privately. Other browser storage keys are excluded. Import is best-effort transactional, with a rollback attempt on failure.
5. **Exam quality disclosure:** Practice-exam selection now displays the dynamically counted bank flags (**224 of 264** need verification). The other 40 are not claimed to be independently verified. A test also checks structural quality of questions; **automated structural checks do not fact-check answers**.
6. **Tests:** Added 8 automated tests for objective mapping/evidence, import/export safeguards, and question-audit logic. 41 tests passed at development time; TypeScript typechecking passed.

## Remaining limitations

- Only **12 of 63** objectives have scenario practice. Linked lessons or confidence ratings do not equate to formal mastery.
- The 264-question bank still requires editorial fact-checking against official Microsoft material, including verifying distractors and explanations. No content has been certified by Microsoft.
- Backup files contain learning data. Keep them safe. Backup import is intended for trustworthy CloudBridge files, not arbitrary JSON uploads.
- Existing V1.2 learning progress is kept in the browser, not stored in the source code or Git. Backups made on one origin are not automatically visible on another.
- The user-provided Azure notes include some additional concepts beyond the exam blueprint; alignment to Microsoft exam objectives should be reviewed periodically.
- **Production bundle not verified in this environment**: the uploaded dependencies are missing the native Rolldown binary and the `.bin/vite` file is not executable. On your own machine run a clean `npm ci` followed by the checks in the upgrade guide.

## Data keys

- New: `cloudbridge-objective-confidence-v1` (independent of previous versions)
- All V1.2 data keys remain unchanged.

## Manual smoke test checklist

1. Open **Learning objectives**, check 63 entries and filter/search controls.
2. Mark one objective **Still learning**, switch to **Scenario practice**, return, verify the rating is preserved.
3. Complete a lesson and a scenario, return to the objectives page, and verify separate lesson completion and practice evidence.
4. Download a backup. Check it contains `format`, `version`, and only CloudBridge progress keys.
5. Make a fresh browser profile for testing; import the backup there and verify the restored lessons, exams, plan, scenario answers, and confidence ratings.
6. Check mobile layout and keyboard navigation.
7. Verify all five practice exams still load and history persists, then run `npm test`, `npx tsc --noEmit`, and `npm run build`.
