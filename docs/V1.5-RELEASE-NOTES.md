# CloudBridge V1.5 — Objective coverage and guided Azure labs

## What changed

- Added **27 original scenario questions**, giving every one of the 63 unique objectives from `Learning objective.docx` at least one mapped scenario (63 scenarios total). This is initial practice coverage, **not** proof of mastery or full exam preparedness.
- Added a **guided Azure Storage lab** with four decision steps: object storage, file shares, zone redundancy and offline transfer.
- Added a **guided Network Access lab** with four decision steps: subnet separation, inbound HTTPS, least-privilege database access and protected administration.
- Added six **supplemental** storage objectives from `Microsoft Azure.docx` and the July 20, 2026 AZ-900 study outline in a separate list. The original 63 handout objectives are unchanged.
- Added storage of completed lab choices in the new browser key `cloudbridge-lab-progress-v1`, and included it in the existing progress export/import allowlist.
- The existing 36 scenario IDs, their localStorage key, learning progress, practice-exam data, planner, and module lessons have not been renamed.

## Source boundaries

**Source-based:** `Learning objective.docx` contains 63 distinct objectives once duplicated cost statements are removed. `Microsoft Azure.docx` contains more complete Azure Storage learning objectives. The supplied documents are the first reference for question scenarios.

**External scope check:** the Microsoft study guide for AZ-900 lists Azure Storage as an explicit exam skill area as of July 20, 2026. https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900

**Not certified:** CloudBridge's 63 scenarios and guided labs are author-created. The new questions are not official Microsoft questions or independently validated by Microsoft. Likewise, one correct response does not demonstrate sustained mastery.

**Simulations only:** labs do not provision resources, call Azure APIs, or test an actual NSG deployment. The networking lab is a conceptual rehearsal for LO-051; learners still require real or supervised hands-on practice to demonstrate configuration.

**Still pending:** formal review of most of the 264-question practice-exam bank, multiple independent assessment items per objective, verified labs in a sandbox, full mobile-browser/manual accessibility QA and a fresh production build.

## Compatibility and rollback

Apply the V1.5 patch only to the unmodified V1.4 release, or merge carefully on a Git branch. Backup progress from the Learning Objectives screen before changing browsers or deploying.

Rollback source: use `git revert` or switch back to the V1.4 commit. Do **not** clear localStorage: the V1.5 lab key is additive and earlier code will ignore it.
