# CloudBridge v1.7.0 — Learning insights and question-review workflow

## Changed

- Adds **Learning insights** navigation and a read-only dashboard with lessons, scenario coverage, latest-per-exam average, AZ-900 domain breakdown, and last five attempts.
- Enables **Practise this domain** actions that open the existing scenario interface with a corresponding category filter.
- Prevents repeated attempts of the same practice exam from distorting the category comparison; historical retakes still appear in the last-five history.
- Clarifies that results are authored-practice outcomes and that zero questions have independent official-content approval.
- Adds an exportable **question-review queue** containing every one of the 264 source questions, with explicit blank approval fields and structural warnings. Run `npm run review:export` to reproduce it.
- Adds 8 regression tests for analytics and review queue, bringing automated test count to 63.
- Adds documented initial, AI-assisted Microsoft Learn cross-checks of five governance questions. These are not human reviewer approvals.

## Preserved

- Lesson catalog, existing question IDs and five examination pools.
- Saved learning progress, exam results, scenario progress, objective confidence, simulated lab results, and backup format.
- React / TypeScript / Vite, GitHub Actions workflow, and Netlify configuration.

## Limitations

- Existing question statuses: 206 flagged for verification, 40 unclassified, 18 notes-reviewed. All 264 remain pending **independent** official-documentation review and editorial sign-off.
- Domain analytics are based on latest completed attempt per distinct practice exam; a small sample, repeated question familiarity or incorrect authored questions can distort results.
- Test suite and TypeScript validation passed in this environment. Vite production build could not run because the existing uploaded dependencies lack the native Linux Rolldown binding. Run a clean `npm ci` and `npm run build` on your machine / CI before deploying.
- No remote website or GitHub repository changed.
