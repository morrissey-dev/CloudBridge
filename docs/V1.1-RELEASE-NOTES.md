# CloudBridge V1.1 — Source-aligned Learning Reliability

## Source materials and boundaries

This release uses the user's two files: **Microsoft Azure.docx** (88 pages of Azure Fundamentals notes) and **Learning objective.docx** (78 bullet entries, 63 distinct after removing repeated cost objectives). They supplied the curriculum and explanatory material. The official Microsoft study guide (skills measured July 20, 2026) was used **only to check the three domain definitions and weights**: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900

No original lessons, flashcards, case studies, or existing question IDs were deleted. This is a targeted upgrade to the source-code archive; the live Netlify site was not edited.

## Implemented and testable

1. **Objective links.** `src/learningObjectives.ts` includes all 63 distinct user-supplied learning objectives, each mapped to an existing module and an introductory lesson. Source text is retained (whitespace normalised only); the deduplicated register is in `docs/learning-objective-alignment.csv`. Modules now show the full list in an expandable panel, with objectives also shown at mapped lessons.
2. **Assessment coverage.** Each knowledge check has 10 questions chosen across topic sections. Round 2 resumes from the next untested concepts. Every one of 103 lessons can appear within two to four attempts (depending on module). Answers/rounds are deterministic so page refreshes do not reshuffle saved choices.
3. **Legacy progress.** Pre-V1.1 assessments without a version flag retain their exact original question order and answers. Retrying them enables the V1.1 rotation. New learners begin with V1.1 questions; previous exam-history IDs and option order remain valid.
4. **Exam composition.** Every practice exam uses 13/18/14 questions across the three subject areas (28.9%/40.0%/31.1%), within the official bands, and question IDs remain non-overlapping across all five exams. For the official domain taxonomy, 18 identity/security questions were retagged to *architecture and services*.
5. **Additional study questions.** Added 18 original notes-derived management/governance items. Each is still marked as requiring an independent content-review sign-off. None is represented as an official Microsoft exam question.
6. **Dashboard.** "Knowledge checks completed" now means distinct modules with a passing assessment, not the number of assessment attempts. Exam results state they are a raw CloudBridge percentage, not a Microsoft scaled certification score.
7. **Regression protection.** Added tests for source-objective alignment, rotating coverage, legacy assessment compatibility, exact category mix, bank data integrity, and distinct pass counts.

## Remaining gaps before a public launch

- The question bank has **264** items, including **224** newly authored items explicitly marked `needs-verification`; these must be reviewed individually for correctness, quality of distractors, currency, and alignment with source notes and official documentation. The 40 original questions are not automatically declared verified either.
- Lessons mapped to objectives are currently mostly definitions and scenarios, **not demonstrations of learner mastery**. Add formative questions or practical exercises per objective, starting with *Configure basic network access for an Azure resource*.
- Mobile visual testing and a clean production Vite build were **not verified in this sandbox**: the archive contained Windows-only native Rolldown packages and internet access was unavailable for installing the required Linux dependency. TypeScript validation and Node-based tests passed. Reinstall dependencies on your Windows computer with `npm ci`, then build before deployment.
- A full UX review and authenticated cross-device syncing are not part of this phase.
