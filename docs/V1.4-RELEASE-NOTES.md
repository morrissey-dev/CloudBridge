# CloudBridge V1.4 — scenario expansion, revision filters and transparent source review

Based on V1.3 with **no changes to stored lesson, exam, confidence, or scenario-progress schemas**. Nothing in this package automatically updates Netlify or GitHub.

## Changes
1. Added **24 original beginner-level case-based questions**, bringing Scenario Practice to **36** with **36 unique objectives** (of 63 mapped from the supplied objective list).
2. Added filters: **All**, **Not attempted**, **Review mistakes**, and each of the three AZ-900 domains. Filtering uses the last saved attempt; questions that become ineligible during submission remain visible until the learner navigates so the feedback is not lost.
3. Added a direct route from **Learning objectives → Practice this objective**, opening the relevant question instead of the first question.
4. Learners see **review counts** and the actual correct choice after a wrong answer, including explanations.
5. Checked 18 existing governance exam questions against the **user's Azure notes** and added review-source information. **Source-checked does not mean Microsoft-verified.** Remaining bank categories: 206 explicitly pending verification, 18 notes-reviewed, 40 unclassified/not independently verified.
6. Added `docs/SCENARIO-COVERAGE-V1.4.csv` and updated `docs/question-review-register.csv` plus a curriculum gap register for next steps.
7. Added automated tests for source-objective coverage and review filters; see `npm test`.

## Retained without modification
- All 103 existing lessons, 5 × 45-question practice exams and their deterministic pools, quizzes, flashcards, planner, objective ratings, backups, localStorage keys, and existing 12 scenario IDs.
- Existing learners' saved scenario answers remain valid; newly added scenarios appear as not attempted.

## Known limitations
- Practice scenarios test **one decision**, not complete mastery or a substitute for Azure hands-on experience.
- Original 264-question exam bank still needs independent content and distractor fact-checks, particularly the 206 pending questions and 40 unclassified items.
- The official AZ-900 guide includes a storage domain that is covered in the long notes but missing from the separate 63-objective list; see the gap register.
- Structural tests and TypeScript validation pass. The production bundle **could not be verified in this environment** because the uploaded dependencies lack the Rolldown Linux native binding. Run `npm ci && npm run build` locally.
- Neither GitHub nor the public Netlify deployment was modified.

## Suggested manual smoke tests
1. Finish a V1.3 scenario on your existing origin; after updating, ensure its result and attempt count remain visible.
2. Choose **Not attempted**, answer a question, verify explanation remains visible until navigating.
3. Answer incorrectly, switch to **Review mistakes** and retake it; correct latest response removes it from the review list.
4. Select a linked objective and click **Practice this objective**; verify the matching scenario opens.
5. Test empty filters, narrow-mobile layout, keyboard-only selection, and screen-reader status announcements.
6. Test all five exams, local backup import/export and study plan before deployment.
