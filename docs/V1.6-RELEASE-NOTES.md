# CloudBridge V1.6 — Assessment transparency and optional hands-on paths

## Summary

1. Expanded author-created scenario practice from **63 to 77**. All 63 original learning objectives still have at least one item; 14 selected objectives now have a distinct second scenario. No existing scenario IDs or saved answers were removed.
2. Added **two optional Microsoft resource paths** to the Azure labs view:
   - Azure Pricing Calculator: compare estimated VM costs, without creating Azure resources.
   - Azure NSG tutorial: may require an authorised Azure subscription and may create billable resources. Learners are warned to review costs, avoid public SSH/RDP exposure and clean up resources.
3. Added checklist persistence under `cloudbridge-hands-on-self-reported-v1`. Progress is strictly learner self-report, **not Azure validation**. Checklists cannot store account details, tokens, subscription IDs or screenshots through the UI. Added new key to the existing version 1 export/import backup format.
4. Added a **per-practice-exam review-status disclosure**, preserving existing question bank, answer data, exam pools and scoring.
5. Added an opt-in CI workflow for clean npm installation, tests, TypeScript checking and production bundling.

## Source and verification boundaries

- The user's `Microsoft Azure.docx` and `Learning objective.docx` were the basis for scenario topics and teaching terms; the July 20, 2026 Microsoft Learn AZ-900 study guide was used as an external *scope check*. The Microsoft Learn pages for the NSG tutorial and Azure Pricing Calculator are direct external resources, **not embedded Microsoft services**.
- No previously unverified exam question has been relabelled as officially verified. Bank remains **264 questions**: **206 marked needs-verification**, **18 notes-reviewed**, **40 unclassified**, **zero officially/independently verified statuses**. Further expert review is necessary.
- Study results and checkbox ticks are **not** a credential, an AZ-900 score prediction, or evidence that real Azure resources were deployed successfully.
- CloudBridge **does not** provision infrastructure, authenticate to Microsoft Entra, collect credentials, or call Azure APIs.

## Compatibility

All V1.5 scenario IDs, guided lab IDs, progress and test history remain unchanged. Only new scenario IDs and a new optional browser storage key are introduced. Existing V1.5 backups can still be imported. New backups can be imported into V1.6; older releases reject the extra key, so export a backup before rolling back.
