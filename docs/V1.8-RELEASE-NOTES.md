# CloudBridge v1.8.0 — Personalised revision from saved practice

## Features

- Adds **Your suggested revision queue** to Learning Insights and Study Plan.
- Reads the **latest completed attempt for each distinct practice exam**, identifies incorrect/unanswered question IDs, and matches eligible exam-objective labels against the user's original 63 source objectives through a curated explicit crosswalk.
- Reads the latest stored answer for each practice scenario. A corrected scenario is no longer counted as an outstanding scenario mistake.
- Recommends the linked lesson and, when available, opens the corresponding scenario for more practice. Opening a module never marks a lesson complete.
- Builds a suggested set of study sessions, limited by the learner's weekly-days and session-duration preferences. Sessions are **suggestions**, not dated appointments; they are neither scheduled nor automatically completed.
- Shows how many errors cannot be confidently linked to the 63-objective handout. Azure Storage and database subjects in the detailed notes are **not** silently mapped onto unrelated handout objectives.
- Provides a domain-level fallback when an unanswered/missed exam question cannot be mapped to the source objectives.
- Adds seven automated regression tests (70 total, up from 63) for retakes, corrections, unmatched questions, fallback behaviour, source-objective mapping and suggested study sessions.

## Preserved

- The existing 63 original source objectives, 77 scenarios, 264 AZ-900 questions, five practice exams and all saved attempt IDs.
- Existing localStorage keys, saved progress and the V1 backup/restore format; no account, database, new storage key or browser-permission request.
- Earlier lessons, flashcards, guided labs, hands-on paths, progress dashboards, and release documentation.

## Limitations and transparency

- Recommendations are derived from **CloudBridge-authored practice**, whose content is largely awaiting independent review. They are not a diagnosis of mastery or an official AZ-900 readiness prediction.
- The exam-objective crosswalk is manually curated. Broad exam question labels may correspond to several objectives; a recommendation is a topic to revisit, not proof that an objective was failed.
- Recommendations use current saved answers. They do not predict an exam score or claim mastery based on one correct practice answer.
- Some question subjects appear in the detailed Microsoft Azure notes but not in the separate 63-objective document. Such mistakes are reported as unmatched rather than incorrectly assigned.
- No questions were independently approved in this release. The outstanding 264-question editorial review backlog remains (18 notes-reviewed; 40 unclassified; 206 flagged for verification).
- Automated tests: 70/70 passed. TypeScript validation passed. Production build remains **unverified** because the available archived Linux dependency tree lacks a native Rolldown binding. Perform clean `npm ci` and `npm run build` locally or in GitHub Actions prior to deployment.
- GitHub, Netlify, and the live CloudBridge website have not been changed.
